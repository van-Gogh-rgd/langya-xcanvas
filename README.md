# 长明局
三集古装短剧的剧本、分镜与制作约束。项目按集协作，每集的改动独立提交和审阅。
《长明局》表面讲的是一批军需如何在天亮前交接，真正争的是：谁有资格把货物写成“已核”，又由谁为这两个字负责。
第一集，梅长苏把清册分为已核与待核，让原本可以整批呈报的结果有了清楚的边界。
第二集，便携灯让核验员能沿箱查看编号和封记，靖王据此坚持只放行、只签认已经核实的部分；誉王则必须在保留意见中留下自己的立场。
第三集，这份记录被带上朝堂，仓廒里的交接办法变成了制度之争。结尾副册与正式清册出现编号差异，只留下疑问，尚不能判定是谁动了记录。
灯让人看清货物，清册让人说清责任。这是三集故事从一个照明难题走向政治冲突的核心。
