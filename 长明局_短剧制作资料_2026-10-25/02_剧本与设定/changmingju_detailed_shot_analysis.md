# 《长明局》镜头分析细化版

本文件用于替换联合主分镜表中较简略的“镜头分析”。人物描写包含情绪、视线、呼吸、手部和停顿；场景描写包含光线、空间层次、道具位置和声音。角色均按原创角色参考图执行。

| 1-06 | 誉王将整批签收文书缓慢推到案边，五指压住纸角后才松开；他身体向前倾一点，语气温和却不让步。梅长苏的手停在另一份清册上，没有接那份整批文书。 | 文书从誉王一侧滑入暖光，纸面反光盖过木案纹理；背景人物保持静止，避免抢走两只手和文书的注意力。 | 用“推文书而非抢文书”表现誉王的体面施压，也让梅长苏的停手成为第一次明确拒绝。 |
| 1-07 | 梅长苏用食指点出正式清册的编号起止，声音放轻，视线只落在纸上；誉王记录员坐在侧后方，听见后迅速低头，笔尖在副册上连续划过几次。抄完后他把副册往袖侧藏，装作只是整理纸张。 | 正式清册在前景清晰，副册只露出窄窄一角；笔尖声与油灯芯爆响并置，梅长苏始终不转头看副册。 | 交代副册来源但不提前泄露异常；前后景的清晰度要明确谁知道什么。 |
| 1-08 | 记录员把副册折起，拇指在封边上压紧；梅长苏听见纸页声，眼睫只动一下，仍盯着誉王推来的整批文书。他抬头问“完整的记录，还是完整的责任”时，目光短暂落到誉王脸上，随后先移开。 | 副册被收入暗紫灰袖口附近，正式清册仍置于暖光中；两种纸张材质和装订颜色要能被看出不同。 | 让观众知道梅长苏在回应整批签收方案，而不是已经发现副册异常。 |
| 1-09 | 靖王转身看向仓门外的天色，鼻翼轻动，压住催促的焦躁；他说“先把能确认的写清”时，手掌按在待核箱方向。誉王收回文书，嘴角仍有笑，但手指在纸边停顿了一下。 | 仓门外更鼓声隐约传入，未验木箱占据画面暗部；誉王收文书的动作与靖王指向未验区形成相反方向。 | 冲突暂时降温，但让两人都留下未完成的动作，推动第二集继续核验。 |
| 1-10 | 核验员重新俯身看箱侧，发现阴影再次盖住编号，笔悬在纸上没有落下；他抬头望一眼油灯，又低头。梅长苏分开的两份清册被风吹起一角，他伸手压住，却没有合拢。 | 油灯火焰拉长，箱体阴影横过编号；清册的两页一明一暗，更鼓声在切黑前留下余响。 | 用同一物理障碍收尾，让观众明确第二集要验证的是照明和流程，而不是新冲突。 |

## 第二集《分签》

| 镜号 | 人物情绪与动作 | 场景细节 | 镜头意图 |
|---|---|---|---|
| 2-01 | 核验员保持上一集的半蹲姿势，手指在编号上方停住；梅长苏抬眼看漏进仓门的微光，再看一眼时辰，轻轻摇头示意不要搬箱。呼吸短而稳，说明他已经有解决方案。 | 固定油灯仍在同一侧，编号被箱体边缘切成半段；案上的两份清册和上一集保持原位置，形成连续性检查点。 | 先复现问题，再让梅长苏用眼神和手势为便携灯具进入留出合理动机。 |
| 2-02 | 核验员从案边拿起便携灯，先用手掌试一下重量，随后沿箱侧移动；他的肩膀放松，步幅小而稳，眼睛始终盯着灯头落点。梅长苏站在后侧观察，不插手。 | 便携灯从冷暗区域进入人物和木箱之间的工作带，灯体蓝色小牛标志短暂露出；箱体位置、演员朝向与前一镜保持一致。 | 建立产品真实使用方式：移动照明、减少挪箱，不表现自动识别。 |
| 2-03 | 核验员拇指缓慢旋动调光旋钮，先低亮对准封记，再提高一点亮度；编号显现后，他眼睛从灯光移到封记，再移到纸面，开口读号。记录员听到后抬头确认，才低头落笔。 | 光线从箱侧阴影逐渐铺到编号和封记，封记表面出现细小反光；记录员的纸面只保留栏线和手部，文字后期替换。 | 把“灯光改善”拆成可见的亮度变化和人工视线链路，避免把判断能力归给产品。 |
| 2-04 | 核验员读完后短促点头，手腕收回，带灯向下一只箱迈出两步；记录员笔尖不停，写完后在栏末压一下，确认这一项结束。 | 镜头横移时，前一只箱的暖亮区域退出画面，下一只箱仍在冷暗处等待；主灯架留在原地，不再被拖动。 | 用连续移动证明流程少了调灯和搬箱中断，但不在画面中宣称固定节省时间。 |
| 2-05 | 记录员按住清册上沿，连续勾记编号；核验员用两根手指托住封记附近，不触碰封记本身，只侧头确认。交接负责人伸手比出箱数，等记录员复述后才点头。 | 木案上墨迹、勾线、封记和箱数形成同一信息链；背景保留低沉车轮声，暗示核验结果会进入交接流程。 | 将数量复核拍成三方互相确认的动作，明确人工责任没有被省略。 |
| 2-06 | 交接负责人先看核验员，再看记录员，确认两人点头后落笔签认；核验员签名时肩膀略紧，完成后才放松。梅长苏把已核清册向前推，把待核清册向后压，动作慢而明确。 | 两份清册在案上形成前后层次但不重叠；印章盒放在右侧，尚未盖下，保留下一步动作空间。 | 让“已验先行、未验另册”通过手部位置直接可见，工具效果和制度策略在同一构图里汇合。 |
| 2-07 | 誉王拿起已签记录，先扫过签认栏，再抬头看剩余木箱；他的笑意变薄，拇指压住纸角，语气仍平和但尾音下沉。梅长苏不接他的视线，只把待核清册留在手边。 | 已签记录处于暖光，未核木箱落在誉王身后的冷暗区域；画面中两种亮度对应两种责任状态。 | 表现誉王第一次看见局面提前推进，从容假面出现细小裂痕。 |
| 2-08 | 靖王双手把已核清册推向发运方向，动作干净不拖；他回头确认待核箱仍在原位，才对搬运人点头。搬运人抬箱时避开案面，不碰待核清册。 | 画面前景是向外移动的已核箱，后景保留未核箱和待核清册；门外冷风带动车帘。 | 用空间分流表现局部放行具备制度依据，避免剪成“整批都已完成”。 |
| 2-09 | 誉王看着分开的清册，先抿嘴，再把目光移向仓门外；他抬手整理袖口，像在恢复体面，随后以平静语气提出明日前补齐。靖王没有回嘴，只继续核对箱数。 | 誉王的暗紫灰袖口在暖光边缘短暂停留；远处运输声逐渐变远，现场压力从“能否放行”转为“何时补齐”。 | 让誉王把失败转化成期限压力，情绪由受阻转为重新布局。 |
| 2-10 | 誉王拿起笔，在保留意见旁停住，先看一眼已出仓方向，再落笔；签完后他把笔放平，指尖在纸边停一拍。待核木箱留在阴影里，核验员回头看它，随后重新举灯。 | 已核箱的车轮声从近到远，待核区只剩油灯和便携灯交叠的光；纸面文字与签名留作后期合成。 | 明确誉王接受局部放行的代价，也为下一集“保留意见”和副册线索留下可见凭证。 |

## 第三集《余局》

| 镜号 | 人物情绪与动作 | 场景细节 | 镜头意图 |
|---|---|---|---|
| 3-01 | 誉王把两份清册并排推到案中央，动作比第二集更快，显示他不愿再等；他用指背敲一下合册位置，抬眉微笑，眼神却锁住梅长苏。 | 两份清册仍保持平行，案面中央留出一条清晰缝隙；便携灯不在画面，避免产品再次抢走文书攻防的重心。 | 进入第二轮权力博弈，强调誉王试图重新收回口径。 |
| 3-02 | 梅长苏没有后退，先把披风衣襟拢紧，再用食指分别点向核验人、签认人和待核范围；他说话时每个落点之间留半拍，眼神从纸面移到誉王。 | 冷蓝侧光勾出披风边缘，三处手指落点形成稳定三角构图；清册边缘和签认栏保持可替换空间。 | 把“不能混同责任”转化为连续的指认动作，表现沉静而主动的掌控。 |
| 3-03 | 靖王先看梅长苏，再看誉王，确认双方都听见后才对记录员点头；他语速不快，手掌平放案面，强调变更必须留下记录。记录员吸气、蘸墨，等待完整指令后才写。 | 记录员位于两位王府人物之间，纸面成为公开规则的承载物；木柱和仓门方向保持对称，减少视觉混乱。 | 让规则从个人判断变成公开程序，誉王无法用口头压力抹掉变更。 |
| 3-04 | 誉王转身指向运输车，手臂伸到一半又收回，避免动作失控；他下颌绷紧，声音仍压低，但最后一个字明显加重。靖王看一眼车，再把视线落回未核清册。 | 仓门外运输车停在冷蓝雾气里，车轮和门槛形成延误的视觉证据；仓内暖光只照到清册边缘。 | 将现实运输压力拉回画面，同时保持冲突在责任边界内。 |
| 3-05 | 靖王面对誉王站直，肩线稳定，先吸一口气再回答；他说“我担职责之内的责”时手指收紧，后半句转向未核清册，眼神不闪躲。誉王听完微微偏头，笑意消失但没有打断。 | 两人之间隔着案面和两份清册，人物距离不变；未核清册位于靖王手侧，像一道不能跨越的界线。 | 完成靖王的立场选择：刚直但不莽撞，拒绝替未核货物承担身份。 |
| 3-06 | 搬运人推走已核木箱，靖王用手势示意路线，交接负责人和核验人分别在纸上盖印；核验员盖完后看向留仓木箱，嘴唇抿紧，再转身继续。 | 已核箱经过暖光出口，未核箱留在冷暗仓内；印章落纸声与车轮声一前一后，形成闭环。 | 用箱体、印章和人物视线同时完成“已核放行、未核留仓”。 |
| 3-07 | 朝堂中靖王双手呈上分项记录，膝和肩保持端正，不做夸张跪拜；他说制度建议时目光向前，语气坚定但不提高。皇帝低头读完，指腹在纸边停住，没有马上抬眼。 | 三层台阶、皇帝案位和屏风形成中轴线；朝堂冷蓝灰，案面暖光落在清册上，远处侍从保持静止轮廓。 | 把仓库现场提升为制度后果，并用皇帝不批示的停顿保留悬念。 |
